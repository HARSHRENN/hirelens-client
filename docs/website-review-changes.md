## Item 22 — admin assignment outcome feedback

Admins can record Successfully closed or Unsuccessful assignment, optional 1–5 rating and performance notes from Job → Assign recruiter or Admin → Recruiter analytics. Reviews are private to admins, stored separately from recruiter-editable job documents, and tied to job ID plus assignment version and recruiter snapshot. They remain attributed to that recruiter after reassignment or job removal. Each assignment has one review; optimistic revisions prevent stale edits and prior content is retained in its history. Recording a review does not change job status, candidate stages or automatic joined-position counts. Analytics adds successful/unsuccessful assignment-review counts using the review’s first-recorded date, independent of candidate/job cohort counts.

Apply `supabase/recruiter-feedback.sql` once to the existing database before publishing. The full schema includes this idempotent migration. Browser verification covered both outcomes, reassignment and editing an older review; SQL tests cover persistence, duplicates, stale updates, privacy, audit history and retained attribution.
